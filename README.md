# Data Analysis & Python Portfolio
This repository contains a collection of projects and exercises demonstrating data manipulation, exploratory data analysis (EDA), and advanced Python programming.

## Key Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn.

### Contents:
- Data Wrangling & EDA: Cleaning datasets, handling missing values, and visualizing data distributions (e.g., Titanic dataset analysis, missile attacks statistics).
- Advanced Python: Object-Oriented Programming (OOP), algorithmic problem-solving, decorators, and data structures.
